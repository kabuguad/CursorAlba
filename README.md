# Alber School — Premium Frontend

Ultra-modern React website for Alber School, Kutus, Kirinyaga County, Kenya.

## Stack

- React 19 + TypeScript + Vite
- Tailwind CSS v4 (glassmorphism theme)
- React Router, Framer Motion, Recharts, Lucide Icons

## Features

- Light/dark theme (persisted in localStorage)
- 360° virtual tour with hotspot teleportation
- 125+ staff directory with search, filters, infinite scroll
- Multi-role demo login (Admin, Teacher, Parent dashboards)
- Full public site: programs, arts, sports, admissions wizard, blog, contact

## Run

```bash
npm install
npm run dev
```

```bash
npm run build
```

## Demo Login

Visit `/login` — select Admin, Teacher, or Parent. Any password works.
